# Screen test plan — xorr-eth app (101 routes)

Strict PASS/FAIL definitions for every expo-router route in `app/`, written against the code as it stood on **2026-09-14** (after the copy distillation: one short line per section, no chain or venue names on the main screens). Where `tools/shoot.mjs` disagrees with the current code, the code wins; the disagreements are listed at the end.

**How to mark a row.** A route **PASSES** only if all of these hold on the reference account:

1. Everything in *Correct when loaded* is on screen, with real data.
2. Each state in *Loading · empty · error* renders exactly as quoted when you cause it.
3. Nothing in *Must not show* appears, and nothing from rule G4 below appears.
4. Every control does what *Controls → result* says.
5. The console shows no errors, and the network log shows no 4xx or 5xx. The one exception is `503`, which is the executor's documented warming handshake.
6. The route is reachable the way *Reached from* says.

*Already looks wrong* lists defects visible in the code today. Expect those items to FAIL, and retest them once they are fixed.

## Global rules (apply to every row)

| # | Rule |
|---|---|
| G1 | **Session.** "Yes" means sign in first through `/wallet` (Privy email OTP; `tools/shoot.mjs` shows how to use Privy test credentials). The button appears only for retryable failures: 5xx, 408, 429, timeouts and network errors, never other 4xx. ### Getting real ids

```sh
export API=${EXPO_PUBLIC_API_URL:-http://localhost:8788}
TOKEN=$(npx tsx server/src/e2e-token.ts ${E2E_PRIVY_EMAIL:-test-8958@privy.io})   # same helper tools/shoot.mjs uses
H="authorization: Bearer $TOKEN"
curl -s -H "$H" $API/positions        | jq -r '.[] | select(.notional >= 0.01) | .id'  # /position/<id>, /auto-close/<id>
curl -s -H "$H" $API/strategies       | jq -r '.[].id'                                  # /strategy/<id>
curl -s -H "$H" $API/agents           | jq -r '.[] | "\(.id)  \(.personaId)  \(.name)"' # /agent/<id|personaId>, /bot/<id>/…
curl -s -H "$H" "$API/runs?limit=200" | jq -r '.[].id'                                  # /runs/<id>
curl -s -H "$H" $API/activity         | jq -r '.[].id'                                  # /audit/<id>
```

Shorthand used in *Reads*: **MKT** = `GET /market/symbols` + `/market/quotes?symbols=…` + `/market/stocks` (`repos.markets.listClasses`, never throws). **PRICE(s)** = `/market/symbols` + `/market/quotes?symbols=s` (+ `/market/stocks` for a `…c` equity). **CANDLES(s,d)** = `/market/symbols` + `/market/ohlc?symbol=s&days=d` (never throws; answers `warming` or `unavailable` instead). **LOGOS** = `/market/logos?symbols=…`. **AGENTS** = `GET /agents` (never throws; falls back to 4 fixture personas). **BAL** = `GET /wallet/balance` via `balance()` (never throws; `null` on failure).

Run the two one after the other: both executors share upstream quotas (1inch, CoinGecko), and running them at once slows both. `QA_EXPECT_VERSION=<sha>` asserts the deployed commit; `QA_ONLY=E042,/market` runs a subset (ids or path substrings). The script never prints, logs or writes the token, and redacts JWTs, agent keys and credential-shaped URL paths from everything it records. It also records whether the executor restarted during the run.

## What "correct" means everywhere

- **Auth.** A private path without a token, or with a forged one, answers `401 {error:"unauthorized", detail}`. `/agent/*` is the agent-key surface: no token, a Privy user token and an unknown `xagt_` key all get 401. Operator-only routes outside it (`/ops/mirror`, `POST /limit-orders`, `POST /privy/policy/prove`) answer a user token with `403 {error:"forbidden"}`. The public surface — the 16 paths `/health` publishes, which `src/data/publicPaths.ts` mirrors, plus the `/perp/` prefix — answers without a token.
- **Named errors.** A refusal carries a machine-readable code, `/^[a-z][a-z0-9_]*$/`, in `error` — or in `reason` beside `status:"blocked"` on the withdrawal, faucet and limit-order routes — plus a sentence in `detail` or `message`. A bad parameter or body is a 400 with such a name: never a 5xx, never a 404 whose message has a hole in it, never a 200 carrying a made-up result.
- **Ownership.** Another account's resource, or an unknown id, on an owned route answers 403/404 — never 200 or 500.
- **Waiting.** A 503 carrying Retry-After (`warming`, `rate_unavailable`) and the limiter's 429 are part of the contract and are waited out, as the app does. No single request may take longer than the app waits for it: 45 s for a read, 180 s for a write (`src/data/api.ts:42,50`).
- **App parameters.** Where the app calls an endpoint, the check sends exactly what the app sends, and the row names the source line.
- **Safety.** Happy paths run only when safe and reversible, and clean up after themselves: alerts created and deleted, draft strategies created and ended, withdrawal addresses added and removed, a no-size proposal created and skipped, an agent's tone changed and restored, the agents stopped and resumed only when no strategy is due, a notification preference flipped and restored. Anything that trades, moves funds, signs on chain, anchors, mirrors, pushes or calls a model is exercised through its refusals only — see the last section.

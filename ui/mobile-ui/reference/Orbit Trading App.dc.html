2 Nine more screens — the flow around the agents

What the research pointed at. The pattern the newest agentic exchanges are converging on: onboarding that asks for goals, risk tolerance and funding in one flow, then has the AI draft a portfolio the user reviews, adjusts and approves — with an explanation attached to every recommendation. CNBC on Kraken's rebuild. Compliance work has moved the same way: agents run ID match, liveness and sanctions screening, and the thing regulators actually ask for is a structured audit trail of every agent action.

So these nine cover: goals → verification → funding → AI proposal → agent roster → agent chat with an approve-before-execute trade → asset detail → order ticket → audit log. All live: chips, steppers, keypad, filters, hire toggles.
